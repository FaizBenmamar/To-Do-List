# To-Do List (Pro)

A clean, responsive to-do list built with HTML, CSS and vanilla JavaScript.

- Add tasks with the **Add task** button or the **Enter** key
- Mark tasks as done, delete them, filter them (All / Active / Completed) and clear completed ones
- Progress bar and task counter
- **History**: a log of every task you ever added, including completed and deleted ones, with timestamps
- Tasks are saved in your browser (localStorage)
- Light and dark mode (follows your system), keyboard accessible, no libraries needed

Built by Faiz Benmamar.
